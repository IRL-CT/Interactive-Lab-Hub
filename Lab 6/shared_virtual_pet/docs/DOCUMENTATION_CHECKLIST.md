# Lab 6 evidence checklist

This checklist follows the parent README's Part C deliverables. Integrate the reviewed draft into the main Lab 6 README yourself after collecting real evidence; this project does not overwrite it.

## Before assembly/demo

- [ ] Record all three team members and actual role/device assignments.
- [ ] Photograph each of the three Pi 5 + APDS-9960 + Mini PiTFT setups; show I2C/SPI connections.
- [ ] Save actual sensor calibration readings/thresholds, ambient conditions and fallback choice.
- [ ] Record broker hostname and topics without passwords.
- [ ] Include the Mermaid architecture diagram with inputs, computation and outputs.

## During technical checks

- [ ] Screenshot dashboard waiting for data, normal state and latest action/player.
- [ ] Screenshot Needs Care and Happy countdown, plus victory message.
- [ ] Photograph PiTFT role, status values and accepted action feedback.
- [ ] Record a complete real three-person round across three Pis/networks.
- [ ] Show card removal/retrigger, swipe cooldown and 2-second cover/release.
- [ ] Record one disconnect/reconnect and explain what the player sees.
- [ ] Verify normal demo has no developer controls and rejects simulated events.
- [ ] Record reset and a new round; keep software tests separate from hardware evidence.

## User testing: 2+ people outside the team

- [ ] Ask expectations before they try the system; record their words accurately.
- [ ] Obtain permission for photos/video and collect actual use evidence.
- [ ] Record what surprised each participant and what they would change.
- [ ] Note confusion, unsuccessful actions, communication between players and design revisions.

## Before submission

- [ ] Replace every TODO in the Part C draft with real evidence or an honest limitation.
- [ ] Add photos/video links, labeled screenshots and explained code snippets.
- [ ] Write the team's own reflection on distributed interaction and sensor events.
- [ ] Explain where computation happened and why; no AI is used by the runtime.
- [ ] Complete actual team contribution table and course-required assistance acknowledgement.
- [ ] Test media links; remove credentials/personal data from logs and screenshots.
- [ ] Review and integrate the draft into Lab 6 README; retain previous work as appropriate.
